【快速启动指南】
─────────────────────────────────────────────────────────────────────────────
【方式一】使用启动脚本（推荐）

Windows 用户：
  双击运行：run.bat

Linux/Mac 用户：
  chmod +x run.sh
  ./run.sh

【方式二】手动启动

1. 创建虚拟环境：
   python -m venv venv

2. 激活虚拟环境：
   Windows:  venv\Scripts\activate
   Linux:    source venv/bin/activate

3. 安装依赖：
   pip install -r requirements.txt

4. 数据库迁移：
   python manage.py migrate

5. 启动服务器：
   python manage.py runserver
